ИСПРАВЛЕНИЯ И УЛУЧШЕНИЯ

1. Исправлены проблемы с кодировкой кириллических символов:

2. Улучшена обработка ошибок в batch-файлах:

   - В случае ошибки выводится понятное сообщение и программа завершается корректно

3. Создан новый batch-файл для быстрой установки зависимостей:
   - install_dependencies.bat - устанавливает все необходимые зависимости с проверками
   - Этот файл объединяет установку и проверки в одном месте

4. Исправлены ошибки в оригинальных batch-файлах:
   - setup.bat теперь проверяет наличие pip и устанавливает его при необходимости
   - Запуск_Программу.bat теперь проверяет успешность запуска Python-скрипта

5. Зависимости:
   - Основная зависимость - Pillow (для модуля PIL в main.py)
   - Также устанавливаются setuptools и wheel для корректной работы pip
