DESCRIPTION:
This utility is designed to fix network issues caused by VPNs, DNS changes, 
and various network tools (zapret-discord-youtube, nekobox, nekoray, adguard, etc.)
that disrupt Windows 11 network settings.

FEATURES:
- Light Reset: Clear DNS cache only (no restart needed)
- Medium Reset: Clear DNS, ARP, NetBIOS cache and reset Winsock (no restart needed)
- Heavy Reset: Reset TCP/IP stack and network adapters (no restart needed)
- Complete Reset: Full network reset (restart recommended)
- All operations include detailed explanations of what they do, risks, and benefits

USAGE:
1. Run as Administrator (required for all network reset functions)
2. Choose the appropriate reset level based on your issue severity
3. Follow the on-screen instructions

RESET LEVELS:
[1] LIGHT - Clear DNS cache only (Recommended for minor issues)
    - No network interruption
    - Quick and safe
    - Fixes temporary DNS problems

[2] MEDIUM - Clear DNS, ARP, NetBIOS cache and reset Winsock (Recommended for moderate issues)
    - May require reconnecting to WiFi
    - Fixes most cache-related network problems
    - Resets Windows socket layer

[3] HEAVY - Reset TCP/IP stack and network adapters (For persistent issues)
    - Requires network reconnection
    - Fixes deep network stack problems
    - Resets TCP/IP to default state

[4] COMPLETE - Full network reset (For severe issues, restart recommended)
    - Removes all network profiles and configurations
    - Like starting fresh, but requires reconfiguration
    - Total network stack reset

TROUBLESHOOTING:
- Always run as Administrator
- If network issues persist after complete reset, consider updating network drivers
- After heavy or complete reset, you may need to reconfigure WiFi networks and VPN settings

DISCLAIMER:
This tool is provided as-is. Use at your own risk. Always backup important network configurations before using heavy or complete reset options.

ОПИСАНИЕ:
Эта утилита предназначена для устранения сетевых проблем, вызванных VPN, изменениями DNS и различными сетевыми инструментами (zapret-discord-youtube, nekobox, nekoray, adguard и др.), которые нарушают сетевые настройки Windows 11.

ВОЗМОЖНОСТИ:
- Легкий сброс: Очистка только кэша DNS (перезагрузка не требуется)
- Средний сброс: Очистка DNS, ARP, кэша NetBIOS и сброс Winsock (перезагрузка не требуется)
- Тяжелый сброс: Сброс стека TCP/IP и сетевых адаптеров (перезагрузка не требуется)
- Полный сброс: Полный сброс сети (рекомендуется перезагрузка)
- Все операции включают подробные объяснения того, что они делают, риски и преимущества

ИСПОЛЬЗОВАНИЕ:
1. Запускать от имени администратора (требуется для всех функций сброса сети)
2. Выберите соответствующий уровень сброса в зависимости от серьезности проблемы
3. Следуйте инструкциям на экране

УРОВНИ СБРОСА:
[1] ЛЕГКИЙ - Очистка только кэша DNS (Рекомендуется для незначительных проблем)
    - Без прерывания сети
    - Быстро и безопасно
    - Исправляет временные проблемы с DNS

[2] СРЕДНИЙ - Очистка кэша DNS, ARP, NetBIOS и сброс Winsock (Рекомендуется для умеренных проблем)
    - Может потребоваться повторное подключение к Wi-Fi
    - Исправляет большинство проблем с кэшем сети
    - Сбрасывает уровень сокетов Windows

[3] ТЯЖЕЛЫЙ - Сброс стека TCP/IP и сетевых адаптеров (Для постоянных проблем)
    - Требует повторного подключения к сети
    - Исправляет глубокие проблемы со стеком сети
    - Сбрасывает TCP/IP в состояние по умолчанию

[4] ПОЛНЫЙ - Полный сброс сети (Для серьезных проблем, рекомендуется перезагрузка)
    - Удаляет все сетевые профили и конфигурации
    - Как начать с нуля, но требует повторной настройки
    - Полный сброс стека сети

ПОИСК НЕИСПРАВНОСТЕЙ:
- Всегда запускать от имени администратора
- Если сетевые проблемы сохраняются после полного сброса, рассмотрите возможность обновления драйверов сетевой карты
- После тяжелого или полного сброса может потребоваться повторная настройка сетей Wi-Fi и настроек VPN

ОТКАЗ ОТ ОТВЕТСТВЕННОСТИ:
Этот инструмент предоставляется как есть. Используйте на свой страх и риск. Всегда делайте резервные копии важных сетевых конфигураций перед использованием тяжелых или полных параметров сброса.
