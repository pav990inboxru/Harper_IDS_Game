Пакет программы таблиц для Stay Out
===================================

Структура пакета:
StayOut_TableManager/
├── main.py                 # Основной файл приложения
├── requirements.txt        # Зависимости Python
├── Запустить_Программу.bat # Файл запуска приложения
├── setup.bat              # Файл установки зависимостей
├── README.txt             # Основная документация
├── FEATURES.txt           # Описание всех функций
├── data/                  # Папка для хранения данных
│   └── products.json      # Файл с данными о товарах
├── docs/                  # Папка документации
│   └── styling.txt        # Описание стилей С.T.A.L.K.E.R.
├── images/                # Папка для изображений (пустая)
└── libs/                  # Папка для дополнительных библиотек (пустая)

Функциональность:
- Создание и управление категориями товаров
- Добавление информации о ценах покупки и продажи
- Указание продавцов/мест продажи
- Добавление изображений к товарам
- Автоматическое сохранение данных
- Вкладки с библиотекой, ссылками и обучением
- Стилизация в стиле С.T.A.L.K.E.R.
- Поддержка русского языка
- Простой интерфейс для новичков

Автор: Harper_IDS
Создано для: IgromanDS игровое сообщество
Тематика: С.T.A.L.K.E.R. стиль для игры Stay Out

Все файлы готовы к переносу и использованию на Windows 11.
