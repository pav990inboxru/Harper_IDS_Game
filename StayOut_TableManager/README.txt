Программа таблиц для Stay Out
=============================

Создано: Harper_IDS
Для игрового сообщества: IgromanDS

Описание:
Программа предназначена для создания таблиц товаров для игры Stay Out.
Позволяет создавать категории товаров, добавлять информацию о ценах покупки и продажи,
указывать продавцов/места продажи и добавлять изображения.

Функции:
- Создание категорий товаров (например, "Грибы", "Оружие", "Броня")
- Добавление товаров с указанием:
  * Название товара
  * Минимальная цена покупки на доске
  * Цена при вашей продаже
  * Продавец или место продажи
  * Дополнительная информация
- Добавление изображений к товарам
- Автоматическое сохранение данных
- Вкладка с полезными ссылками по игре
- Вкладка с обучением по использованию программы

Запуск:
Для запуска программы используйте файл "Запустить_Программу.bat"
Или выполните команду: python main.py

Требования:
- Python 3.6 или выше
- Библиотека Pillow (устанавливается через pip install -r requirements.txt)

Установка:
1. Убедитесь, что у вас установлен Python 3.6+
2. Установите зависимости: pip install -r requirements.txt
3. Запустите программу: дважды щелкните по "Запустить_Программу.bat"
