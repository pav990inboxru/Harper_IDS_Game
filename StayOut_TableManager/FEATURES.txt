Особенности программы таблиц для Stay Out
=========================================

1. Создание категорий товаров:
   - Возможность добавлять/удалять категории (например, "Грибы", "Оружие")
   - Автоматическое сохранение данных

2. Управление товарами:
   - Добавление товаров с указанием:
     * Название товара
     * Минимальная цена покупки
     * Цена при вашей продаже
     * Продавец/Место продажи
     * Дополнительная информация

3. Визуальные элементы:
   - Добавление изображений к товарам
   - Стилизация в стиле С.T.A.L.K.E.R. (темная цветовая схема)

4. Организация интерфейса:
   - Многостраничный интерфейс с вкладками:
     * Таблицы товаров - основная вкладка для управления категориями и товарами
     * Библиотека - вкладка для просмотра созданных таблиц
     * Ссылки - полезные ссылки по игре (Steam, вики, профиль автора)
     * Обучение - инструкция по использованию программы

5. Система автоматического сохранения:
   - Все данные сохраняются в JSON формате в папке data/
   - Автоматическое создание резервных копий при изменениях

6. Упрощенный интерфейс:
   - Интуитивно понятные кнопки и элементы управления
   - Четкое разделение функций
   - Простая навигация между вкладками

7. Тематическое оформление:
   - Цветовая схема в стиле С.T.A.L.K.E.R. (зеленовато-серые акценты на темном фоне)
   - Соответствие атмосфере постапокалиптической игры

8. Дополнительные функции:
   - Возможность загрузки внешних таблиц
   - Диалоги подтверждения при удалении
   - Обучение для новичков

9. Файлы запуска:
   - setup.bat - для установки зависимостей
   - Запустить_Программу.bat - для запуска приложения
   - requirements.txt - список зависимостей

10. Авторство:
    - Автор: Harper_IDS
    - Создано для игрового сообщества IgromanDS
    - Поддержка русского языка

Программа готова к использованию на Windows 11 и других системах с Python.
