ИНСТРУКЦИЯ ПО ЗАПУСКУ ПРОГРАММЫ Stay Out Таблица товаров

Программа для создания таблиц товаров для игры Stay Out
Создано Harper_IDS для игрового сообщества IgromanDS

Функции:
- Создание категорий товаров (например, "Грибы", "Оружие")
- Добавление товаров с указанием:
  * Название товара
  * Минимальная цена покупки
  * Ваша цена продажи
  * Продавец/Место продажи
  * Дополнительная информация
- Добавление изображений к товарам
- Автоматическое сохранение данных
- Интерфейс в стиле С.T.A.L.K.E.R.
- Вкладки: Таблицы товаров, Библиотека, Ссылки, Обучение

КАК ЗАПУСТИТЬ ПРОГРАММУ:
1. Убедитесь, что у вас установлен Python 3.6 или выше
2. Запустите файл setup.bat для установки зависимостей
3. Запустите файл "Запустить_Программу.bat" для запуска приложения

Для пользователей Windows 11:
- Убедитесь, что включен режим выполнения скриптов (если нужно)
- Запускайте .bat файлы от имени администратора, если возникают проблемы

ПРОБЛЕМЫ И РЕШЕНИЯ:
- Если возникает ошибка с tkinter, убедитесь, что Python установлен с поддержкой GUI
- Если программа не запускается, проверьте, что все файлы находятся в одной папке
- Убедитесь, что у вас есть права на выполнение .bat файлов

Для разработчиков:
- Запуск через Python: python main.py
- Зависимости: pip install -r requirements.txt
