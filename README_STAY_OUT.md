# Программа таблиц для игры Stay Out

## Описание
Программа создана для упрощения отслеживания цен на доске объявлений в игре Stay Out. 
Позволяет создавать категории товаров, вести учет цен покупки и продажи, указывать 
кладовщиков и места продажи, добавлять иконки и ссылки на товары.

## Особенности
- Упрощенный интерфейс, удобный даже для детей
- Стилизация в тематике СТАЛКЕР
- Автоматическое сохранение данных
- Возможность добавления иконок к товарам
- Вкладки с полезными ссылками на игру
- Библиотека сохраненных таблиц

## Установка и запуск

### Windows:
1. Убедитесь, что у вас установлен Python 3.x
2. Установите зависимости: `pip install -r requirements.txt`
3. Запустите программу: дважды кликните по файлу `Запуск_Программы_Таблиц_StayOut.bat`

### Linux/Mac:
1. Убедитесь, что у вас установлен Python 3.x
2. Установите зависимости: `pip3 install -r requirements.txt`
3. Запустите программу: `./запуск_программы_таблиц_stay_out.sh`

## Использование
1. Создайте категорию товаров (например, "Грибы")
2. Добавьте товары в категорию с указанием:
   - Названия товара
   - Минимальной цены покупки на доске
   - Вашей цены продажи
   - Имени кладовщика
   - Места продажи
3. Добавьте иконку и ссылку на товар при необходимости
4. Данные автоматически сохраняются при работе
