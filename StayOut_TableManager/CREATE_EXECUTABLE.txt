СОЗДАНИЕ ИСПОЛНЯЕМОГО ФАЙЛА (EXE) ДЛЯ WINDOWS

Для создания исполняемого файла программы под Windows без необходимости установки Python:

1. Установите PyInstaller:
   pip install pyinstaller

2. Запустите команду для создания исполняемого файла:
   pyinstaller --onefile --windowed --icon=icon.ico main.py
   (если файла icon.ico нет, команда будет без иконки)
   
   Полная команда:
   pyinstaller --onefile --windowed main.py

3. После выполнения команды в папке dist/ будет создан файл main.exe

4. Создайте ярлык для удобства запуска или переименуйте exe-файл в "Таблицы товаров для Stay Out.exe"

АЛЬТЕРНАТИВНЫЙ МЕТОД:
Если PyInstaller не работает, можно использовать команду:
pyinstaller --onedir --windowed main.py

Это создаст папку с исполняемым файлом и всеми необходимыми библиотеками.

ВАЖНО:
- Убедитесь, что все зависимости установлены перед созданием exe-файла
- Для работы программы на других компьютерах может потребоваться установленная библиотека Visual C++ Redistributable
