# Stay Out Timer

Stay Out Timer - это программа для отслеживания игрового времени в STALKER. Программа отображает как реальное, так и игровое время с соотношением 1 реальная секунда = 6.87 игровых секунд (настраивается в настройках).

## Особенности

- Отображение реального и игрового времени в формате ЧЧ:ММ:СС
- Настраиваемое соотношение игрового времени (по умолчанию 6.87)
- Цветовая дифференциация кнопок:
  - Зелёная: Старт
  - Оранжевая: Пауза
  - Синяя: Стоп
  - Красная: Сброс
  - Фиолетовая: Изменить время
- Удобный ввод времени через цифровые шкалы
- Нажатие Enter для запуска/паузы таймера
- Будильники с настраиваемым звуком
- Система настроек с вкладками (общие, внешний вид, звук, дополнительные)
- Автосохранение состояния и настроек
- Справочник для новичков
- Оформление в стиле STALKER
- Автономная работа без подключения к интернету

## Управление

- **Старт**: Запуск таймера (зелёная кнопка)
- **Пауза**: Приостановка таймера (оранжевая кнопка)
- **Стоп**: Остановка таймера без сброса (синяя кнопка)
- **Сброс**: Сброс таймера в ноль (красная кнопка)
- **Изменить время**: Установка начального времени через шкалы (фиолетовая кнопка)
- **Enter**: Быстрый запуск/пауза таймера
- **Меню "Файл"**: Сохранение/загрузка состояния, выход
- **Меню "Настройки"**: Открытие окна настроек
- **Меню "Справка"**: О программе и справочник

## Структура проекта

- `stay_out_timer.py` - основной файл приложения
- `stalker_icon.ico` - иконка в стиле STALKER
- `build.py` - скрипт для сборки исполняемого файла
- `settings.json` - файл настроек (создается автоматически)
- `state.json` - файл состояния таймера (создается автоматически)
- `dist/` - папка с готовым исполняемым файлом
- `build/` - временные файлы сборки

## Сборка исполняемого файла

Для сборки исполняемого файла используется PyInstaller:

```bash
python build.py
```

Готовый исполняемый файл будет находиться в папке `dist/` и называться `StayOutTimer` (или `StayOutTimer.exe` на Windows).

## Зависимости

Программа использует следующие библиотеки Python:
- tkinter (встроенный)
- pygame (для воспроизведения звуков будильника)

## Настройки

Программа поддерживает настройку следующих параметров:

### Общие
- Соотношение игрового времени (1 реальная секунда = ? игровых секунд)

### Внешний вид
- Тема оформления (default, dark, stalker)
- Цвета интерфейса

### Звук
- Включение/отключение звука
- Громкость будильника
- Файл звука будильника

### Дополнительные
- Автосохранение настроек
- Положение окна при запуске

## Файлы конфигурации

- `settings.json` - сохраняет настройки программы
- `state.json` - сохраняет текущее состояние таймера

## Будильники

Программа поддерживает установку будильников, которые срабатывают при достижении определенного игрового времени. При срабатывании будильника:
- Воспроизводится звук (если включен)
- Показывается всплывающее сообщение
- При необходимости может подаваться системный сигнал

## Справочник

В меню "Справка" доступен справочник с описанием всех функций программы.

## Лицензия

Программа создана как автономное приложение без ограничений на использование.
