# Установка и запуск Stay Out Timer на Windows 11

## Способ 1: Использование готового исполняемого файла

1. Перейдите в папку `dist`
2. Найдите файл `StayOutTimer.exe`
3. Дважды кликните по файлу для запуска

## Способ 2: Использование скрипта запуска

1. Запустите файл `start_stay_out_timer.bat`
2. Приложение запустится автоматически

## Создание ярлыка на рабочем столе

1. ПКМ по рабочему столу → "Создать" → "Ярлык"
2. В поле "Расположение объекта" укажите путь к `StayOutTimer.exe`
3. Назовите ярлык "Stay Out Timer"
4. (По желанию) Измените иконку, выбрав `stalker_icon.ico`

## Особенности приложения

- Приложение работает в режиме таймера реального и игрового времени STALKER
- Соотношение времени: 1 реальная секунда = 6.87 игровых секунд (настраивается в настройках)
- Поддерживает функции: старт, пауза, стоп, сброс, установка будильника
- Автосохранение состояния и настроек
- Тема оформления в стиле STALKER

## Горячие клавиши

- Enter: запуск/пауза таймера
- Ctrl+Q: выход из приложения (в будущих версиях)

## Возможные проблемы

Если приложение не запускается:
- Убедитесь, что у вас Windows 11 (или Windows 10)
- Проверьте, что файл не удален антивирусом
- Попробуйте запустить от имени администратора
